# Security Policy

## Supported Versions

Security fixes are handled on a best-effort basis for the latest main branch state.

## Reporting a Vulnerability

Please do not open a public issue for security-sensitive reports.

Instead, email [hello@andreaswissel.com](mailto:hello@andreaswissel.com) with:

- a description of the issue
- impact and affected area
- reproduction steps if available
- any suggested mitigation

We will acknowledge good-faith reports as quickly as possible and coordinate on disclosure timing when a fix is needed.

## What To Expect

- Initial acknowledgment on a best-effort basis
- Private triage and reproduction
- A fix or mitigation plan when the report is confirmed

## Safe Harbor

We appreciate responsible disclosure that avoids:

- accessing data that is not yours
- degrading service availability
- modifying or deleting user data

If you act in good faith and follow this policy, we will treat your report as a responsible disclosure.
