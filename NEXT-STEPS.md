# NEXT-STEPS.md — Future Exploration

## Project Enhancements

- **Project-level shared context** — OKRs, customer feedback, and docs inherited by all sessions in a project
- **Project dashboard** — Aggregated view of all session outputs (specs, strategies, GTM materials)
- **Cross-project search and insights** — Find patterns and themes across multiple projects
- **Drag-and-drop sessions** — Move sessions between projects
- **Project templates** — Pre-configured contexts for common project types (new feature, migration, redesign)
- **Collaborative multi-user projects** — Shared projects with role-based access
- **Agent memory across sessions** — Agents remember context from previous sessions in the same project
- **Project export** — Bundle all specs, strategies, and GTM materials into a single document
- **Per-project integration config** — Map a project to a specific Jira board or Slack channel
- **Project archiving** — Archive completed projects without deleting them
