# Support

- Setup help: [docs/setup.md](docs/setup.md)
- Connector setup: [docs/integrations.md](docs/integrations.md)
- E2B setup: [docs/e2b.md](docs/e2b.md)

## Questions, Bugs, and Ideas

- Open a GitHub issue for reproducible bugs
- Open a GitHub issue for feature requests with concrete use cases
- Open a pull request if you already have a proposed fix

Maintainer support is best-effort.

## Security Issues

Do not report vulnerabilities in public issues.

Use [SECURITY.md](SECURITY.md) for private security reporting instructions.
